# FPTR formula font

The website embeds the unmodified **Latin Modern Math 1.959** OpenType font so
native MathML uses one stable font on every supported platform.

- File: `latinmodern-math.otf`
- SHA-256: `6075562b771f8b82f0c179e363389684f2dd09de30038269e2628e504bd7be0f`
- Authors: Bogusław Jackowski, Piotr Strzelczyk, and Piotr Pianowski
- License: GUST Font License / LPPL 1.3c or later

The accompanying `GUST-FONT-LICENSE.txt` and
`MANIFEST-Latin-Modern-Math.txt` are preserved from the upstream font
distribution.
