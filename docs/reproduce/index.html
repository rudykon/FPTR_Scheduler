04 · 复现路径

复现

下面的命令从公开样例开始，完整覆盖编译、运行与独立验证。

C++17 · Python 3

快速开始

调度结果写入标准输出，可选阶段轨迹只写入标准错误，因此诊断不会污染分配格式。

克隆并编译

git clone https://github.com/rudykon/FPTR_Scheduler.git
cd FPTR_Scheduler

g++ -std=c++17 -O2 \
  src/scheduler.cpp src/core.cpp \
  -o scheduler

运行公开样例

mkdir -p /tmp/fptr-samples /tmp/fptr-output
cp space/data/cases/small-balanced.in \
  /tmp/fptr-samples/small-balanced.in
./scheduler \
  --stage full \
  --budget-ms 87 \
  --trace \
  < /tmp/fptr-samples/small-balanced.in \
  > /tmp/fptr-output/small-balanced.out

独立验证

python3 tools/scheduler_validator.py \
  --samples /tmp/fptr-samples \
  --output-dir /tmp/fptr-output
快速实验 
python3 experiments/paper_experiments.py \
  --quick \
  --out /tmp/fptr-quick-results
预期结果 valid_runs: 1/1 验证器重新解析输出、检查全部约束并重算目标值。
