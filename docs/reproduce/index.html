04 · 复现路径

从编译到独立验证，只需要三步。

调度结果写入标准输出；可选阶段轨迹写入标准错误，因此诊断不会污染分配格式。

审计边界

论文中的每个结果，都能落到一次进程启动、一个生成实例或一组校验工件。

一次 launch 是拥有独立输入流、执行顺序、随机种子和墙钟测量的子进程。质量以每个实例五次运行的中位数为单位，并在五个场景内先求平均、再等权汇总；置信区间使用 5,000 次分层 bootstrap。

  1. 01
    独立启动

    固定实例、配置、随机种子与预算。

  2. 02
    序列化输出

    分配写入标准输出，阶段轨迹只写入标准错误。

  3. 03
    独立验证与重算

    Python 代码重新解析结果、检查全部约束并重算传输量。

  4. 04
    统一计分与哈希

    迟到、非法或异常退出计零分；输入、源码和结果由 SHA-256 链绑定。
